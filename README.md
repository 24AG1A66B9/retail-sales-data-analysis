# 📊 Retail Sales Data Analysis & Business Insights

## 📌 Project Overview

This project performs **Retail Sales Data Analysis and Business Insights** using Python.

The project uses **Pandas** for data loading, cleaning, and analysis, along with **Matplotlib** and **Seaborn** for data visualization.

A **Streamlit dashboard** is also included to provide an interactive way to explore the retail sales data.

---

## 🎯 Objectives

- Load and clean retail sales data.
- Handle missing values.
- Remove duplicate records.
- Correct inconsistent data.
- Analyze sales, profit, and quantity.
- Analyze product and category performance.
- Analyze customer-related statistics.
- Analyze regional performance.
- Identify important trends and patterns.
- Create meaningful data visualizations.
- Generate useful business insights.

---

## 🛠️ Technologies Used

## 🧹 Data Cleaning

The project performs the following data-cleaning operations:

- Removal of duplicate records
- Handling of missing values
- Conversion of date columns
- Conversion of numeric columns
- Removal of unnecessary spaces
- Standardization of category names
- Standardization of region names
- Handling of invalid dates
- Data type correction

The project analyzes:

## 💡 Business Insights

The application automatically identifies:

- Highest-sales category
- Highest-profit category
- Highest-sales region
- Highest-profit region
- Best-selling product
- Top customer by sales
- Overall profit margin
- Monthly sales patterns
- Relationship between sales and profit

These insights can help understand product demand, regional performance, sales trends, and profitability.
